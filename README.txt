وب‌سایت شخصی حانیه معتمدی
===========================

فایل اصلی سایت: index.html
رنگ‌بندی: بنفش و کرم
زبان: فارسی (راست‌چین)
طراحی: واکنش‌گرا برای موبایل و دسکتاپ

انتشار با GitHub Pages:
1) فایل ZIP را از حالت فشرده خارج کنید.
2) وارد مخزن GitHub خود شوید.
3) فایل‌های داخل پوشه hanieh-personal-site را مستقیماً در ریشه مخزن بارگذاری کنید؛ خود پوشه را به‌عنوان یک پوشه تودرتو آپلود نکنید.
4) مطمئن شوید index.html در ریشه مخزن قرار دارد.
5) از Settings > Pages، گزینه Deploy from a branch را انتخاب کنید.
6) شاخه main و پوشه /(root) را انتخاب و Save کنید.
7) پس از چند دقیقه، نشانی سایت در همان بخش Pages نمایش داده می‌شود.

نکته: برای افزودن ایمیل یا شبکه‌های اجتماعی واقعی، لینک بخش «ارتباط با من» را در index.html ویرایش کنید.
